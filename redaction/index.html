What it is

Redaktion is an automated detect-and-remove engine for sensitive documents. It finds personal and confidential information across dozens of configurable categories, burns opaque boxes at exact coordinates with true content removal, strips document metadata, and produces a forensically inert file — not an image with a hidden layer underneath.

It began inside SeKondBrain's legal platform and now runs as a dedicated service. It is a Labs product: the engine is proven in production, and we are opening it up to integration partners.

How it works

Three moves, in order. Detect: an ensemble finds sensitive spans across the configured categories, in all three languages. Remove: it deletes the underlying text and overwrites pixels at exact coordinates, then scrubs metadata, attachments and bookmarks from the output. Verify: it re-reads what it just produced and runs detection again — if anything survived, the document is escalated to human review rather than released.

Fail-closed by design

A page the pipeline cannot process confidently is blacked out in full rather than passed through. The original pixels never reach the redacted output — the safe failure is a page you can re-run, not a leak.

Your data

Your source document is encrypted at rest with a per-file key; the redacted artifact is written back encrypted too. Removal is real — text is deleted, pixels overwritten, metadata stripped — so the output cannot be un-redacted by copying a layer or reading document properties.

The audit trail records where each redaction happened — page, position, category, confidence — but never the sensitive text itself: it stores a keyed one-way digest, so the log cannot be mined for the very data it removed. Working files are swept on a short timer, and processing runs on EU/Swiss-resident infrastructure. Full detail is in the privacy policy.
